Design specification · v1.0 · July 2026

LightWeaver

A native Windows media client for Jellyfin. The chrome is a storm-quiet darkness; the media — posters, backdrops, video — is the light being woven through it. Every interactive state is expressed as light: diffuse, restrained, alive.

WPF · Windows 11 mpv native playback dark only 1000×700 → 4K
01

Foundations

Base surfaces carry a cold indigo cast — never neutral gray. Elevation is depth of storm cloud: higher surfaces are marginally lighter and bluer. Interaction is stormlight: a cool luminous white with a blue-teal haze. Accents are gemstones, lit from within.

Rounded rects with circular-arc corners — a deliberate approximation of Material's squircle, because a true superellipse would need a Path/clip per component and bypass the token layer. --r-full and --r-pill share the value 999 but stay distinct: a change to the chip family must not drag every button with it.

The two 999 swatches above lie about the implementation, and they cannot be fixed here — CSS and WPF disagree. CSS border-radius: 999px scales both corner radii proportionally, so the swatch renders as a true stadium. WPF's Border clamps the horizontal and vertical arc radii independently (x to width/2, y to height/2), so the same value draws the ellipse inscribed in the box — a lens on anything wider than tall. Measured on a 510×60 Border: 0 of 510 columns flat at 999, against the 450 a stadium needs; only height/2 (30) gives 450. In XAML, "full" is therefore not a constant: the full-round families bind LwRFullFromHeight to each element's own ActualHeight. --r-full / --r-pill remain defined at 999 for square consumers only, where the clamp yields a true circle. Read the swatches as intent, not as a value to copy.

Asymmetric glow: light arrives fast (240 ms) and decays slowly (420 ms), like an infused gem losing charge. No spring/overshoot easings anywhere. Translations are small (≤ 8 px) and paired with opacity.

04

Implementation notes

Glow, cheaply. All blooms are WPF DropShadowEffect (blur ≤ 28, shadow-depth 0) or pre-rendered radial brushes. No full-screen blur anywhere; the modal scrim is a solid tint.
OSD airspace. mpv renders into a child HWND; OSD chrome lives in a layered top-level window synced to the video window's bounds — avoids WPF airspace clipping and survives fullscreen exclusive-ish modes.
Ornament budget. The woven pattern is one tiled 64×64 drawing brush at ≤ 0.06 α, used only on login, empty states, and section dividers. Never behind poster grids or video.
Contrast. --text-1/2/3 hold ≥ 4.5:1 on storm-1 and storm-2. On artwork, text always sits on a ≥ 0.6 α scrim gradient, never raw.
Fonts. Marcellus, Source Sans 3, JetBrains Mono — all SIL OFL; ship as embedded TTFs. Fallback stack: Segoe UI, Segoe UI Variable.
Scale. Reference layout 1440×900 at 100%. Below 1160 px width the nav rail collapses; above 2560 px, card sizes step up 1.25× rather than reflowing wider rails.
