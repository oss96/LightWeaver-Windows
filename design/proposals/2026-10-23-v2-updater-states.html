Settings › Updates: the updater's states

v2 has no working updater: Settings › Updates only shows "Version X is available" after a manual check, and the policy it saves is read by nothing. The WPF app checks at start and every six hours, downloads and verifies the setup, installs on demand or on exit, and shows its state in Settings and a banner. The handoff draws one Updates state (up to date, SettingsPane.dc.html); the others are not drawn.

Suggestion: the drawn pane in every state within the system

  • Version row. As drawn: "LightWeaver 2.0.0", "Last checked …" under it once a check has run, and the state as the row's value (13, LwText2Brush, at most 320 wide, wrapping). An error reads in LwErrorBrush. A download adds the Downloads row's 4 px track (LwTrackBrush, fill LwAccentFgBrush, 160 wide) before the percentage.
  • Foot. One accent button, as the drawn foot has one: the action the state offers, with Check for updates beside it as a plain button. When checking is all there is to do, Check for updates is the accent button, as drawn.
  • Policy. The chooser stays; its first choice reads "Notify me, install when I choose", because it still checks at start and every six hours (it said "Only when I check").
  • Toast. Outside Settings, the 14c info toast says once per version that an update was found (notify-only policy) or is ready, with "Open" (Settings › Updates) or "Install now". No banner and no badge: the handoff draws neither.
